أولاً: تفعيل البرنامج بكود التفعيل

  1. تأكد أن الحاسوب متصل بالإنترنت.
  2. شغّل البرنامج. ستظهر نافذة Activation (عند انتهاء التجربة، أو من القائمة About ثم Activate).
  3. في الحقل Serial number اكتب كود التفعيل المطبوع مع نسختك، بهذا الشكل:
    MFD-XXXXX-XXXXX-XXXXX-XXXXX
  4. اضغط Activate.
  5. تظهر رسالة Activated. صار البرنامج مفعّلاً مدى الحياة.

مهم:

  • كل كود يعمل على حاسوب واحد فقط. إذا أُدخل على حاسوب آخر تظهر رسالة أن الكود مستخدم.
  • يلزم الإنترنت وقت التفعيل فقط. بعدها يعمل البرنامج بدون إنترنت.
  • يمكنك إعادة إدخال الكود نفسه على نفس الحاسوب (مثلاً بعد إعادة تثبيت البرنامج).
  • التجربة المجانية 10 أيام قبل طلب الكود.
  • إذا لم يكن معك كود: اضغط زر WhatsApp في نافذة التفعيل لطلب رقم تسلسلي.
  • احتفظ بالكود في مكان آمن ولا تعطه لأحد.

ثانياً: إضافة البرنامج إلى Google Chrome

هذه الإضافة تلتقط التحميلات من المتصفح وترسلها إلى البرنامج. يجب أن يكون Maria Free Download مفتوحاً.

  1. في Chrome اكتب في شريط العنوان:
    chrome://extensions
    ثم اضغط Enter.
  2. فعّل Developer mode (زر في أعلى الصفحة).
  3. اضغط Load unpacked.
  4. اختر مجلد الإضافة extension. للوصول إليه بسرعة: من قائمة Start افتح
    Maria Free Download ثم Browser Extension Folder.
    أو من مجلد التثبيت (غالباً C:\Program Files\Maria Free Download\extension).
  5. اضغط Select Folder. تظهر الإضافة في القائمة.
  6. اضغط أيقونة القطعة (Extensions) بجانب شريط العنوان، ثم اضغط دبوس الإضافة لتثبيتها في الشريط.

ملاحظات:

  • لا تحذف مجلد extension ولا تنقله بعد إضافته، وإلا تتوقف الإضافة.
  • إذا ظهر تنبيه Chrome بشأن Developer mode عند فتح المتصفح، اختر إبقاءها.
  • الخطوات نفسها في متصفح Microsoft Edge: افتح edge://extensions.
  • عند إغلاق Maria Free Download، يحمّل المتصفح بشكل عادي.

Maria Free Download – README

1. Activating with an activation code

  1. Make sure the computer is online.
  2. Start the program. The Activation window appears (when the trial ends, or via About → Activate).
  3. Type the activation code printed with your copy into Serial number:
    MFD-XXXXX-XXXXX-XXXXX-XXXXX
  4. Click Activate.
  5. You will see Activated. The program is now activated for life.

Important:

  • Each code works on one computer only. On another computer it is reported as already used.
  • Internet is needed only while activating. Afterwards the program works offline.
  • You can enter the same code again on the same computer (e.g. after reinstalling).
  • The free trial is 10 days before a code is required.
  • No code? Click WhatsApp in the activation window to request a serial number.
  • Keep your code safe and do not share it.

2. Adding the program to Google Chrome

The extension captures browser downloads and sends them to the program. Maria Free Download must be running.

  1. In Chrome, type chrome://extensions in the address bar and press Enter.
  2. Turn on Developer mode (top of the page).
  3. Click Load unpacked.
  4. Choose the extension folder: Start menu → Maria Free Download → Browser Extension Folder, or C:\Program Files\Maria Free Download\extension.
  5. Click Select Folder. The extension appears in the list.
  6. Click the puzzle icon (Extensions) next to the address bar and pin the extension.

Notes:

  • Do not delete or move the extension folder after adding it.
  • If Chrome warns about Developer mode on start, keep it enabled.
  • Microsoft Edge: same steps at edge://extensions.
  • When Maria Free Download is closed, the browser downloads normally.
